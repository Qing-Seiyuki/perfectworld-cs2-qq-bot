# 已绑定玩家的完美比赛自动播报

`qq_cs2_bot.perfect_monitor` 每 90 秒检查已验证、已开启个人播报的群友在完美平台的新比赛。仅群总开关也开启、且已配置官方群 OpenID 到实际 QQ 群号的路由时，才通过本机 NapCat 专用账号推送。战报包含地图、比分、我方五人、击杀/死亡/助攻、完美 Rating 和 ADR。

首次监控某个群友时，现有最近比赛只作为起点，不补发旧比赛。之后发现的新比赛会等详情完整后再推送。同一群同一场只发一份。发送前复核两层开关；QQ 返回确定的消息编号才记录为已发送。发送结果不确定时记录为 `unknown`，不自动重发，防止刷屏。服务停机超过 24 小时的待处理比赛也不会补发。

本机配置群路由：

```powershell
python -m qq_cs2_bot.perfect_monitor --route-group-openid 群OpenID --route-qq-group QQ群号
```

本机开启群总开关：

```powershell
python -m qq_cs2_bot.group_control --group-openid 群OpenID --on
```

群友完成验证后发送 `@机器人 播报 开`，可用 `播报 状态` 检查；`播报 关` 或 `解绑` 会停止该群友的新比赛播报。运行服务：

```powershell
python -m qq_cs2_bot.perfect_monitor
```

需要 `.env` 中已有可用的 `PERFECT_TOKEN`、`PERFECT_STEAM_ID`、`NAPCAT_ACCESS_TOKEN`，NapCat 在本机运行。官方 QQ 机器人处理群指令，主动赛后消息由已入群的播报专用 QQ 账号发送。
