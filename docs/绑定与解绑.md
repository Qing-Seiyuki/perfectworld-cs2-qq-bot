# 绑定、网页登录验证与解绑

在群里选中 @机器人，发送 `绑定 <你的17位SteamID64>`。机器人会建立当前群、当前发送者的
待验证申请。发送 `我的绑定` 可查看状态和申请编号；发送 `解绑` 删除自己的绑定。
`称呼 Qing_snow` 设置战报中显示的群内称呼；该称呼由用户自行设置。
`个人播报 开`、`个人播报 关` 只控制自己在当前群的比赛订阅；原有的 `播报 开`、`播报 关` 仍可使用。`播报 状态` 分别显示个人订阅和全群总开关，`群播报 状态` 可单独查看群总开关。开启个人订阅前必须完成账号验证。解绑会清除个人开关，不影响群总开关。
群总开关仅能由机器人维护者在本机设置，群消息中的 `群播报 开/关` 不会修改它；QQ 群管理员身份也不自动获得此权限：

```powershell
.\.venv\Scripts\python.exe -m qq_cs2_bot.group_control --group-openid 群OpenID --on
.\.venv\Scripts\python.exe -m qq_cs2_bot.group_control --group-openid 群OpenID --off
```

个人和群总开关默认关闭。目标群路由已配置且监控服务正在运行时，两项都开启、绑定已验证的群友会收到此后新结束比赛的战报；服务说明见 [自动播报](自动播报核心.md)。

## 使用 Steam 官方网页登录验证

项目维护者在运行机器人的同一台电脑上启动本机回调：

```powershell
.\.venv\Scripts\python.exe -m qq_cs2_bot.openid_local --request-id 申请编号
```

程序在本机浏览器打开 Steam 官方登录页面。用户只在 Steam 网站确认登录。
成功后，Steam 把签名结果重定向到本机 127.0.0.1 回调地址。
程序向 Steam 再次核验签名，确认返回的 SteamID 与当前待验证申请一致，随后标记已验证。
十分钟内未完成则关闭本机服务，可重新启动。成功后在群里发送 `我的绑定` 查看状态。

本机回调只适用于使用这台电脑浏览器的用户；其他群友若要自助绑定，后续需部署他们能访问的
HTTPS 回调服务。当前不要求用户修改 Steam 个人简介或名称，也不读取用户 Steam 密码。
Steam 登录只确认 SteamID 的控制权，不授予完美平台比赛列表访问权。
依据：[Steam 官方身份验证文档](https://partner.steamgames.com/doc/features/auth)。

## 简化战报

验证后，在群里 @机器人发送 `战报 <比赛ID>`，机器人会用发送者当前群绑定的
SteamID 定位我方队伍，并把已验证群友自行设置的称呼显示在战报中。
其他群或待验证的绑定不会显示称呼。

## 查询自己的最近比赛

已验证绑定的群友可发送 `@donk666 /我的比赛` 查看最近一场的完整五人战报，或发送 `@donk666 /我的比赛 9` 查看最近第 9 场。发送 `@donk666 /我的比赛列表` 可看第 1 页的 8 场简表；`@donk666 /我的比赛列表 2` 显示第 9～16 场。列表中的编号可直接用 `@donk666 /9` 选择，编号始终按最近到较早排序。列表只显示时间、地图、胜负与比分，详细战报仍使用完美 Rating。

## 玩家战绩查询（数据接入中）

在群里 @机器人发送 `数据 ❀Lèa!!!❀`，按完美平台昵称精确搜索；
也可直接发送 `数据 <SteamID64>`，按 17 位 SteamID64 精确查询，无需先绑定。
同名玩家会列出各自 SteamID 和当前天梯分；再发送 `数据 选中的SteamID` 选择目标。
旧指令 `战绩` 仍可使用。
搜索会还原平台返回的 HTML 字符实体，因此 `è` 等字符可以正常匹配。

当前可返回昵称、SteamID 和搜索接口提供的当前天梯分。历史最高段位及对应赛季 Rating、
当前赛季 Rating、最近五场平均完美 Rating 尚无稳定可用的数据来源，因此不会填造数值或
给出异常判断。收到平台客服提供的获准数据入口后，接入已完成的五场平均与三项阈值规则。
规则分别为最近五场平均完美 Rating > 1.35、比当前赛季平均高 > 0.30、当前赛季
完美 Rating > 1.35；只要满足其一便显示统计提醒，并明确不等同于违规判定。

## 本机存储

SQLite 数据库位于 data/bot.sqlite3，已加入 .gitignore。身份以
AppID + group_openid + member_openid 隔离；这些 OpenID 不是原始 QQ 号码。
绑定请求在群内只能由本人操作；已验证的同一 SteamID 在同群只允许一个绑定。
解绑会删除关联、验证状态及称呼。本机备份若存在，可能仍保留历史记录。
消息去重表保留七天的消息 ID，不保存聊天正文。

十分钟的本机测试模式：

```powershell
.\.venv\Scripts\python.exe -u -m qq_cs2_bot.qq_listen --seconds 600 --bindings
```
